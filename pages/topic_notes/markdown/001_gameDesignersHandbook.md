### Part 1: Definitions

#### Defining Game

- Set up phase:
  - Everything ready to start gameplay
- Play phase:
  - going through gameplay
  - Consider player goal here
- Finish phase:
  - Player's goal in gameplay loop is complete
- Gameplay loop
  - Series of major actions in play phase
  - Objective=> challenge=> reward =>objective
    - Objective:
      - Accomplish to progress game
    - Challenge:
      - Overcome to complete objective
    - Reward
      - Receives / avoids in game
      - Eventually find new objective
  - Successful loop rewards in 3rd beat that feeds back to 1st beat to maintain loop
    - Modern games have mulitple loops
  - Core game play loop
    - Where players spend most time so devs should polish this one a tone
- Spliter cell example
  - Complex games will have many loops
  - Every dungeon has a gameplay loop
  - Plan=>execute=>vanish=>plan
    - Plan
      - Strategize
    - Execute
      - Main challenge in loop
    - Vanish
      - advance in game to stealth mode
- GAME LOOP
